# Печать героя (Hero Typing)

Веб-приложение: геймифицированный тренажёр слепой печати с визуальным обучением, глубокой аналитикой, звуковым движком и соревновательным PvP-режимом в реальном времени.

Разработано в рамках хакатона «Киберрывок 2026».

- Онлайн-версия проекта: https://eventus-project.ru/
- Локальный запуск: полностью поддерживается за 2 минуты (Windows / Linux / macOS)

---

## 1. О проекте

«Печать героя» переосмысливает обучение слепому десятипальцевому методу печати. Вместо монотонных тренажёров пользователь погружается в соревновательную среду с визуальным контролем правильного положения пальцев, системой уровней, комбо-множителями, достижениями, интеллектуальным анализом ошибок и сетевыми дуэлями 1 на 1.

Интерфейс выполнен в тёмной минималистичной дизайн-системе (стиль Linear / Monkeytype / Vercel), ориентированной на читаемость, эстетику и концентрацию на тексте.

## 2. Ключевые возможности

### Визуальное обучение слепой печати
- Интерактивная виртуальная клавиатура ANSI:
  - Полная раскладка с функциональными рядами и клавишей пробела.
  - Динамическое переключение символов под текущий язык (RU / EN) и регистр (Shift).
  - Тактильные риски на опорных клавишах (А/О и F/J).
  - Цветовая маркировка зон ответственности каждого из 10 пальцев.
  - Подсветка целевой клавиши и парной клавиши Shift с противоположной руки.
  - Мгновенная индикация опечатки (световой импульс красного цвета).
- Векторная SVG-схема кистей рук:
  - Стилизованная анатомическая схема 10 пальцев с подсветкой активного пальца прямо во время набора.
  - Подсказка в реальном времени: «Следующая клавиша: О - Правый указательный палец».
  - Возможность скрытия клавиатуры для опытных пользователей клавишей или кнопкой в интерфейсе.
- Автодетектор неверной раскладки:
  - Предупреждение при случайном наборе латинскими буквами в русском тексте и наоборот.

### Режимы тренировки
- Слова: словарный запас из слов длиной от 2 до 10 букв на русском и английском языках.
- Предложения: осмысленные тексты с естественной пунктуацией и синтаксисом.
- Код: сниппеты с реальным синтаксисом на Python, JavaScript и HTML / CSS.
- Символы: интенсивный тренинг спецсимволов, скобок, цифр, формул и запросов.
- Умный режим «Слабые клавиши»: алгоритм анализирует накопленные ошибки пользователя и генерирует персональное упражнение с высокой концентрацией проблемных символов.

### Глубокая геймификация
- Уровни и опыт (XP): формула начисления опыта учитывает чистую скорость (CPM), точность (%), длительность упражнения и множитель комбо. Формула уровня: level = 1 + (xp // 500).
- Комбо-множители:
  - x1 - базовый множитель;
  - x2 - от 15 верных нажатий подряд;
  - x3 - от 35 верных нажатий подряд;
  - x5 - от 70 верных нажатий подряд.
  - Динамическая смена цвета рамки бейджа комбо и тактильный микро-импульс.
- Уровни сложности:
  - Базовый (Ур. 1) - стандартный опыт;
  - Продвинутый (Ур. 2) - бонус +25% XP;
  - Эксперт (Ур. 3) - бонус +50% XP.
- Система достижений: 7 наград (Первый шаг, Быстрые пальцы, Печатный гений, Стальной палец, Снайпер, Мастер кода, Ветеран клавиатуры) с сохранением в профиле и фанфарным звуковым эффектом.

### Соревновательный PvP-режим (Дуэли 1 на 1)
- Сетевой подбор игроков в реальном времени: очередь ожидания на WebSocket (/ws/pvp) со счётчиком времени поиска.
- Экран Versus (VS):
  - Плавная анимация появления карточек претендентов.
  - Отображение аватара, имени игрока, рекорда WPM и текущего уровня.
  - Обратный отсчёт старта: 3... 2... 1... СТАРТ! с пульсирующей анимацией.
- Сдвоенный трек гонки (Dual Split Race Track):
  - Одинаковый текст для обоих соперников для объективности состязания.
  - Плавное синхронное движение бегунков по треку.
  - Индикатор отрыва в реальном времени: «Лидируете на +X симв.» / «Отставание X симв.».
  - Мгновенная передача прогресса соперника по протоколу WebSocket.
- Итоги дуэли:
  - Начисление +120 XP за победу и +40 XP за участие.
  - Сравнительная таблица результатов: Скорость (WPM), Точность (%), Время и Количество ошибок.

### Аудиосистема с нулевой задержкой (Web Audio API)
- Декодирование tap.mp3 в нативный AudioBuffer в оперативной памяти браузера без задержек HTML5 Audio.
- Отклик менее 1 миллисекунды при каждом нажатии клавиши.
- Процедурные синтезированные звуки ошибки, завершения раунда и разблокировки достижений.
- Удобное включение и выключение звука одной кнопкой в верхней панели.

### Аналитика и Таблица лидеров
- Интерактивные графики Chart.js: динамика WPM / CPM и точности (%) по последним 30 тренировкам.
- Анализ проблемных клавиш: частотный рейтинг ошибок с кнопкой быстрого запуска целевой тренировки.
- Таблица лидеров:
  - Фильтры периода: За сегодня, За неделю, За всё время.
  - Сортировка: По опыту (XP), По скорости (WPM), По точности (%).
  - Бейджи лидеров пьедестала и выделение строки текущего пользователя.

## 4. Быстрый запуск

### Способ 1. Автоматический запуск в 1 клик (Рекомендуемый)

#### Для Windows:
Запустите файл двойным кликом в проводнике или выполните в консоли:
```cmd
start_local.bat
```
Либо через PowerShell:
```powershell
.\start_local.ps1
```
Скрипт проверяет наличие Python и Node.js, устанавливает зависимости при первом старте, поднимает Backend на порту 8000, Frontend на порту 3000 и открывает сайт в браузере.

#### Для Linux / macOS:
```bash
chmod +x start_local.sh
./start_local.sh
```

---

### Способ 2. Ручной пошаговый запуск

#### Шаг 1. Запуск Backend (FastAPI)

1. Откройте терминал в корне проекта и установите зависимости:
```bash
pip install -r backend/requirements.txt
```

2. Инициализируйте структуру базы данных:
```bash
python backend/seed.py
```

3. Запустите сервер API:
```bash
python -m uvicorn main:app --app-dir backend --reload --port 8000
```
- Сервер доступен по адресу: http://127.0.0.1:8000
- Интерактивная документация API (Swagger UI): http://127.0.0.1:8000/docs
- База данных SQLite сохраняется локально в файле `backend/hero_typing.db`

#### Шаг 2. Запуск Frontend (React + Vite)

1. Откройте второй терминал и перейдите в каталог `frontend`:
```bash
cd frontend
npm install
```

2. Запустите dev-сервер:
```bash
npm run dev
```

3. Откройте приложение в браузере: http://localhost:3000 (прокси запросов к /api и /ws настроен на порт 8000).

## 5. Документация Backend API

- `POST /api/auth/register` - регистрация пользователя (username, email, password), генерация JWT-токена.
- `POST /api/auth/login` - вход по логину или email и паролю, генерация JWT-токена.
- `GET /api/user/me` - получение профиля текущего пользователя, списка полученных достижений, статистики и истории сессий.
- `POST /api/sessions` - сохранение тренировки, начисление очков опыта (XP), перерасчет уровня, обновление статистики проблемных клавиш и проверка условий для достижений.
- `GET /api/leaderboard?period=today|week|all&sort_by=xp|wpm|cpm|accuracy` - получение таблицы лидеров (топ-20) с фильтрацией и сортировкой.
- `GET /api/achievements` - каталог доступных достижений системы.
- `GET /api/health` - проверка статуса доступности API сервиса.
- `WebSocket /ws/pvp` - протокол обмена данными для соревновательного PvP-режима.

## 6. Продакшн-развертывание

Проект опубликован и функционирует в промышленном контуре:
- URL: https://eventus-project.ru/
- Архитектура развёртывания:
  - Nginx настроен как обратный прокси с поддержкой SSL (Let's Encrypt), сжатием Gzip и HTTP/2.
  - Статический билд фронтенда оптимизирован через Vite (`npm run build`) и отдаётся Nginx с кешированием ассетов.
  - Backend функционирует под управлением Systemd (`hero-typing.service`) на базе Uvicorn с автоматическим перезапуском при сбоях.
  - WebSocket-соединения проксируются через директиву Nginx Upgrade на endpoint `/ws/pvp`.
  - База данных SQLite расположена на защищённом дисковом томе сервера.
